# Quản lý tài liệu thư viện

Bài tập nhóm: chương trình Java quản lý Sách, Tạp chí, Báo.

## Thành viên
| Họ tên | Phần việc | File |
|---|---|---|
| Ngô Anh Tuấn | Các lớp tài liệu, tổng hợp | TaiLieu, Sach, TapChi, Bao |
| Nguyễn Duy Trung | Lớp quản lý | QuanLyTaiLieu |
| Trần Xuân Bách | Menu, nhập liệu, kiểm thử | Main, README |

## Cách chạy
javac -encoding UTF-8 *.java
java -Dfile.encoding=UTF-8 -Dsun.stdout.encoding=UTF-8 Main

## Chức năng
Thêm tài liệu, xoá theo mã, hiển thị, tìm theo loại, thoát.
